# PlantAI 🌱

基于 SwiftUI 的 iOS 植物探索应用，结合 AI 植物识别、虚拟花园与 AR 户外探索。

## 功能模块

- AI 植物识别：接入通义千问视觉模型。
- 虚拟花园：植物图鉴、培育互动与花园场景。
- 户外探索：地图、AR 导航和探索任务。

## 运行

1. 使用支持 iOS 18.5 的 Xcode 打开 `PlantAI.xcodeproj`。
2. 在 Signing & Capabilities 中选择自己的开发团队。
3. 如需使用 AI 识别，在 Xcode 的 Build Settings 中添加用户自定义设置 `QWEN_API_KEY`，填写自己的通义千问 API Key。请勿将该设置提交到公开仓库。
4. 选择兼容设备运行；相机和 AR 体验需要设备支持及相关权限。

这是作品集项目，部分内容为演示数据。本次上传未进行编译或设备测试。

## 技术

Swift / SwiftUI、ARKit、地图与定位、通义千问视觉模型接口。
